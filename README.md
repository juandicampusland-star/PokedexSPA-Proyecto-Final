# 🟥 Pokédex SPA
## Proyecto Integrador #2 - HTML, CSS y JavaScript

---

# 📖 Descripción

En este proyecto desarrollarás una **Pokédex** completamente funcional utilizando únicamente:

- HTML5
- CSS3
- JavaScript (Vanilla)
- Fetch API
- PokéAPI

El objetivo es aplicar todos los conocimientos adquiridos durante el módulo de JavaScript para construir una **Single Page Application (SPA)** que consuma una API real y muestre información dinámica.

Durante este proyecto aprenderás a consumir servicios REST, manipular el DOM y trabajar con datos obtenidos desde Internet.

---

# 🎯 Objetivos

Al finalizar el proyecto serás capaz de:

- Crear una SPA.
- Consumir una API REST.
- Utilizar Fetch API.
- Comprender async y await.
- Manipular objetos JSON.
- Crear interfaces dinámicas.
- Utilizar Arrays.
- Utilizar Objetos.
- Trabajar con Eventos.
- Manipular el DOM.
- Implementar búsqueda.
- Implementar paginación.
